# Схема БД

Текущее предложение для PostgreSQL 16 и порядок согласования описаны в
`../db/README.md`. SQL находится в `../db/proposals/`, не в автоматически
применяемом каталоге миграций. Существующая база в рамках этой работы не менялась.

Старое описание прототипа сохранено в `../demo/docs/database_previous.md`.
Таблица `dataset_state` относится только к FastAPI-прототипу. Финальные миграции
и их учёт версий должны подключаться к отдельному runner серверного разработчика.
