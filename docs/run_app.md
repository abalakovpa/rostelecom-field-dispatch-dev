# Просмотр карты

Локальный демонстрационный запуск: `.\demo\start.ps1` из корня проекта.
Открыть <http://127.0.0.1:8083>. Подготовка Python-окружения — `../demo/README.md`.
Демо использует файлы и память; общая PostgreSQL и `.env` команды не читаются.

В итоговом приложении серверный разработчик отдаёт `web/` через Fastify и реализует
контракт `ui_api.md`. Общие Compose, `.env.example` и установщик принадлежат ему.
Самостоятельного рабочего FastAPI-сервера в корне проекта больше нет.
