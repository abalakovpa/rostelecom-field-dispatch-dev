# Переносимый HTTP-прогон

Ветка test/portable-http основана на интегрированной feature/dispatcher-app.
Скрипт scripts/check_scenario_api.py проверяет именно этот проект и его
схему dispatch в PostgreSQL. Он не предназначен для Fastify-ветки.

## Изоляция

PUT /reference заменяет данные сервиса. Использовать отдельный API-контейнер
и отдельную тестовую БД, не работающий стенд команды. Отдельный Compose-проект
создаёт отдельный том; его порты тоже должны отличаться от рабочего стенда.
Перед запуском проверить, что URL и параметры БД относятся к одному экземпляру.
Скрипт не может доказать это до первого PUT; одно лишь имя БД не гарантирует
изоляцию удалённого HTTP-сервера.

Создать .env.qa (не коммитить) с POSTGRES_HOST, POSTGRES_PORT, POSTGRES_DB,
POSTGRES_USER, POSTGRES_PASSWORD для тестовой БД. Имя базы произвольное,
но должно точно совпадать с --test-database.

После установки requirements-dev.txt в Python 3.12:

    python scripts/check_scenario_api.py --url http://127.0.0.1:8080 --db-env .env.qa --test-database dispatcher_qa --allow-reset --plan-limit 5 --output data/qa

Применять реальный адрес запущенного тестового API; на исходном Compose
по умолчанию порт 8083. Изменения его порта этот коммит не содержит.
Параметр --plan-limit 5 — быстрый функциональный прогон. Для оценки качества
выделить до 300 секунд и выполнить отдельный полный прогон.

## Результат

В новой папке data/qa сохраняются JSON-ответы, время HTTP-запросов,
версии планов, отчёт JSON и после успешного завершения Markdown.
При ошибке остаётся частичный report.json; процесс завершается с ошибкой.

Сохраняются существующие сценарии шести типов событий, проверки схем,
H1–H10, истории, повторов и отката через снимки PostgreSQL. Добавлены
ошибочная структура, неизвестный сотрудник, задержка неактивного визита
и корректное событие после отклонённых запросов.

Проверка семантической ошибки ожидает 422 согласно OpenAPI. Если приложение
возвращает 409, это ошибка прогона, а не автоматически разрешённое исключение.
Известный конфликт обеда остаётся явно отмеченным ограничением исходного теста.

Локально выполнена проверка синтаксиса. Свежий HTTP/PostgreSQL-прогон этой
версии ещё не выполнен; положительного результата сквозной проверки пока нет.
