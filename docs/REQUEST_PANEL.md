# Панель создания заявок

Для защищённой сети ЦОД по решению пользователя и эксперта вход по логину
и паролю отсутствует. PANEL_PASSWORD больше не используется и не создаётся.
Старое значение в .env можно удалить, на запуск оно не влияет.

После обновления проекта:

    bash scripts/deploy-panel.sh

Панель: http://SERVER_IP:8082/. Карта через панель: /map.
PANEL_PORT и PANEL_BIND переопределяются в .env; по умолчанию 0.0.0.0:8082.
Отдельный профиль Compose panel запускает форму, основной API остаётся прежним.

Выберите адрес, тип работ, дату и начало желаемого двухчасового слота.
Форма передаёт заявку Fastify API и показывает фактическое назначение.
Демонстрационные справочники можно загрузить кнопкой только в пустую БД:
при существующих сотрудниках/днях загрузка отклоняется с 409.

Адреса взяты из data/, произвольные адреса вне матрицы не поддерживаются.
Потребность тестовой заявки: ONT для PON и ROUTER, контрольный срок — 3 дня.
Это параметры генератора для проверки, не универсальные нормативы.
Сеть и разграничение доступа обеспечиваются инфраструктурой размещения.
