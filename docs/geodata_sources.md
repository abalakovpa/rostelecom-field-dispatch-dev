# Источники геоданных и повторное получение

Адреса и контуры — OpenStreetMap, Орджоникидзевский район Екатеринбурга,
relation **5819002**. Источники: <https://www.openstreetmap.org/relation/5819002>,
OSM API <https://api.openstreetmap.org/api/0.6> и Overpass
<https://overpass.private.coffee/api/interpreter> (можно задать `OVERPASS_ENDPOINT`).
Данные OSM распространяются по ODbL; атрибуция © OpenStreetMap contributors
сохранена на карте: <https://www.openstreetmap.org/copyright>.

Сохранены выбранные 80 домов и 5 мест для синтетических СЦ в
`data/provenance/real_locations.json`: OSM ID, теги адресов, контуры и точки,
проверяемые внутри домов/района. Это обработанный набор для воспроизводимых
проверок расположения маркеров, а не большая исходная выгрузка. Телеком-атрибуты
и назначение зданий сервисными центрами синтетические.

Скачанные `osm_download_*.cache` и `osm_ordzhonikidzevsky_raw.json` исключены
из набора для интеграции. Локально сохранены в игнорируемом `tmp/geodata-cache/`.
Скрипт теперь читает и пишет исходные выгрузки только туда.

## Заново получить адреса

Из корня проекта, в окружении с `certifi`, PyYAML и jsonschema:

```powershell
.\.venv\Scripts\python.exe scripts/fetch_real_buildings.py
```

По умолчанию скрипт запрашивает границу района и адресные жилые дома через Overpass.
Альтернатива через OSM API и ограниченные прямоугольники:

```powershell
$env:OSM_DIRECT='1'
.\.venv\Scripts\python.exe scripts/fetch_real_buildings.py
Remove-Item Env:OSM_DIRECT
```

При наличии локальной выгрузки используется кэш. Чтобы запросить новые данные,
сначала отдельно сохраните прежний кэш и выберите пустой `tmp/geodata-cache/`.
Онлайн-данные со временем меняются; побитовое повторение старой выгрузки не обещается.
Для обычного запуска карты эта команда не нужна.

## Матрица и генерация тестовых файлов

Реальная направленная матрица `data/travel_matrix.json` уже включена в набор.
Небольшой `data/provenance/osrm_table.json` оставлен для воспроизведения матрицы
без скачивания: содержит ответ OSRM и хэш порядка координат. Источник дорожной
матрицы — `http://router.project-osrm.org/table/v1/driving/`.

При намеренной замене выбранных зданий нужно получить новую дорожную матрицу:

```powershell
.\.venv\Scripts\python.exe scripts/generate_data.py --fetch-osrm
.\.venv\Scripts\python.exe scripts/validate_data.py
```

Эти команды перезаписывают синтетические файлы `data/`; без необходимости их
не запускают. Если координаты прежние, генератор использует сохранённую матрицу
без `--fetch-osrm` и проверяет хэш координат. Прямой геометрический заменитель
времени в пути не используется. Ничего из этого не обновляет командную БД.
