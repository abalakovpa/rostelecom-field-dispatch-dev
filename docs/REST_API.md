# REST API: текущая реализация

Семь операций /api/v1 зарегистрированы в Fastify по схемам официального
api_spec.yaml. Ошибки формата — 400, несогласованные ссылки — 422,
неверный порядок вызовов — 409, отсутствующий день/план — 404.
Вход ограничен 100 МБ. Неизвестные дополнительные поля не используются.

Хранилище PostgreSQL: миграция 002_api_state.sql. Изменения сериализуются
блокировкой строки FOR UPDATE и сохраняются одной транзакцией. Ошибка
расчёта откатывает событие, модельное время и изменения дня.
Это первая реализация: хранение матрицы в общем JSON-снимке требует
нагрузочной проверки и дальнейшего разделения таблиц.

## Подключение расчёта — ещё требуется

В этой ветке нет адаптированного Python-планировщика. В Compose задаётся
PLANNER_URL — HTTP POST endpoint, принимающий внутренний объект:

    { reference, matrix, day, previous_plan, event }

reference, matrix и day — официальные входные объекты, day.now уже отражает
событие; NEW_ORDER включён в day.orders. previous_plan — предыдущий Plan
или null, event — текущее официальное событие или null. Остальные события
применяет адаптер расчёта, используя предыдущий план и модельное время.
В ответе ожидается официальный Plan. Сервер выставляет дату, версию,
модельное время и based_on_event_id, проверяет схему, учёт нарядов и
неизменность начатых остановок. При отсутствии PLANNER_URL возвращается
503 PLANNER_UNAVAILABLE, состояние не меняется.

Этот интерфейс предложен со стороны сервера и ещё не согласован с Павлом.
Его plan(request) напрямую данный объект не принимает. До адаптации нельзя
считать дневной расчёт и обработку всех событий завершёнными.

## Проверки

Из api:

    npm ci
    npm run build
    node --test tests/api.test.mjs

Тесты используют транзакционный memory-store и подставной расчёт для
проверки HTTP-слоя. Это не интеграционные проверки PostgreSQL и планировщика.
Полный сценарий и производительность на 350–450 нарядах ещё не проверены.
Для серверного запуска требуется применить миграцию и настроить PLANNER_URL.
Не заменять работающий стенд этой веткой до готовности адаптера.
