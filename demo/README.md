# Локальная демонстрация, не итоговое приложение

Здесь сохранён прежний прототип: FastAPI, экспериментальный планировщик OR-Tools,
их тесты, SQL импорта и вспомогательные инструменты. Командный REST API делает
серверный разработчик на Fastify; итоговый планировщик — Павел. Этот код не должен
автоматически попадать в их приложения или заменять их инфраструктуру.

## Посмотреть карту

Из корня проекта:

```powershell
python -m venv .venv-demo
.\.venv-demo\Scripts\python.exe -m pip install -r demo/requirements.txt
.\demo\start.ps1
```

Открыть <http://127.0.0.1:8083>. На текущем компьютере можно использовать уже
подготовленное окружение `.venv`; скрипт найдёт его автоматически.
Запуск через Python: `.\.venv\Scripts\python.exe demo/start.py`.
Это файловая демонстрация: `.env` в корне не читается, PostgreSQL не используется,
планы/события хранятся в памяти. На карте отображается пометка «Демо».
Для подключения к Fastify нужно отдавать `web/` и реализовать `contracts/ui-api.yaml`.

## Что обсудить с Павлом

| Код | Потенциальная польза | Статус |
|---|---|---|
| `backend/planner/validate.py` | Воспроизведение ограничений и заморозки начатых остановок | Кандидат для сравнения с проверками Павла |
| `backend/planner/risks.py` | Пересчёт ETA и жизненный цикл предупреждений | Кандидат, не согласован |
| `backend/planner/events.py` | Примеры сохранения начатой части маршрута | Алгоритм замены не согласован |
| `backend/planner/solver.py` | Экспериментальная эвристика и тестовые примеры | Не командный планировщик |
| `tests/` | Граничные случаи допуска, оборудования, событий, обеда | Переносить после согласования |

Вопрос обеда выбывшего сотрудника остаётся отложенным. Строгое поведение прототипа
не менялось, см. `../docs/open_questions.md`.

## Проверки прототипа

```powershell
.\.venv\Scripts\python.exe -m pytest -c demo/pytest.ini demo/tests -q
```

Это отдельный набор тестов, не проверка Fastify. Тесты PostgreSQL требуют явного
`RUN_POSTGRES_LOAD_TESTS=1` и отдельной базы `dispatcher_next*`; автоматически
они не запускаются. Старые инструкции и результаты в `docs/` описывают прототип,
а не договорённый командный сервер.

`compose.yaml`, `.env.example` и `backend/api/Dockerfile` в этой папке принадлежат
только демонстрации. Образ PostgreSQL в демо — 16. Они не заменяют общие файлы
команды. Каталог `db/migrations/002_dataset_state.sql` нужен только FastAPI;
общая схема в `../db/proposals/` ещё требует согласования.
